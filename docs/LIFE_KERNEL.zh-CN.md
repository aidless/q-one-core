# Q-One 0.3：可学习的人生状态与决策内核

日期：2026-10-25。应用接入版本：q-one-life 0.5。

## 这次改变了什么

旧内核主要负责事件记录，应用把平面目标和待办交给语言模型排序。这不能支持一个有深度的人生系统。

新链路：**有测量口径的个人状态 → 用户声明的价值与目标树 → 完整资源消耗 → 显式情景或历史训练的变化预测 → 多目标方案比较 → 人工采纳 → 后续观察与历史回放**。

已经实现的是可训练的小数据预测基线和有限行动组合比较器。没有训练通用“人生大模型”，没有复现 DreamerV3 / TD-MPC2，没有真实用户收益实验。复杂人生的长期动力学仍然是待研究的问题。

## 人生模型的深度来自关系和时间

| 对象 | 表达内容 | 不应替代的内容 |
|---|---|---|
| 维度 | 可扩展的关注范围、层级 | 已验证的心理量表 |
| 价值声明 | 用户明确说重视什么、为何取舍 | 从点击行为推断的真实价值 |
| 测量定义 | 对象、口径、单位、量表、有效期 | 任意0到100分 |
| 观察 | 发生时间、登记时间、来源、更正链 | 模型生成的影响假设 |
| 目标 | 成功条件、父子关系、关联价值 | 完成了任务就自动达成人生目标 |
| 资源账户 | 单位、预算、有效窗、已承诺消耗 | 只有一个每日时间数字 |
| 行动 | 前置条件、完整耗时、资源成本、验收 | 模型自由编造的下一步 |
| 影响假设 | 来源、支持状态、增量或类别变化、延迟 | 已识别的因果效应 |
| 底线 | 不允许牺牲的具体条件 | 可被其他维度高分抵消的惩罚项 |
| 学习记录 | 实际执行的行动组合和前后观察引用 | 采纳、点击、任务完成带来的伪奖励 |

### 八个起始维度只是可编辑目录

1. **身体与恢复**：区分可用体能/注意力存量、睡眠和活动等行为流、主观感受和外部限制。设备记录、用户自述分别保留。未建立医疗诊断模型。
2. **学习与能力**：知识/技能存量需要通过固定口径的独立验收观察；学习时长是投入，不能直接当能力增长。遗忘、迁移、任务难度属于未来模型需要解释的机制。
3. **工作与创造**：已验收成果、未完成工作、外部需求、承诺和可用机会分别表示。忙碌和任务数量不等于价值创造。
4. **物质与资源**：时间、可支配资金、可用设备和外部支持分别建账户；存量、收入流、支出流不混用。当前实现只有显式预算和消耗，尚无完整资产负债动态账本。
5. **关系与支持**：保留用户选择的关系类别、互动事实、可获得支持与本人感受。不能把他人的价值或亲密关系变成单一分数。
6. **环境与生活条件**：居住、通勤、工具和干扰等约束；许多障碍需要改变环境，而不是不断增加个人任务。
7. **自主与意义**：原话、承诺、主动选择与价值冲突；可以保留定性条件和需要本人审阅的目标，不强迫量化。
8. **休闲与体验**：投入、恢复感和满意度分开记录；不把所有体验变成产出目标。

这些维度支持交叉连接：一个行动可服务多个目标、消耗多个资源、影响多个测量。目录本身不提供心理测量效度，也不是八个独立评分卡。示例只填入部分测量；空白维度保持未建模。

### 量表语义

- 比率/区间量表：仅在相同单位与定义内进行数值运算；没有自动换算。
- 有序类别：仅比较顺序与条件是否满足，不计算类别之间的距离。
- 名义类别：相等检查；没有高低之分。
- 定性文字：保留原话与显式条件。
- 未分类：禁止参与数量目标运算。

没有“人的总分”。各目标缺口分别保留原单位，不能将睡眠、收入、友情与意义直接相加。

## 时间、来源与可恢复性

观察同时包含 `observed_at` 和 `recorded_at`。历史状态只读取当时已经发生且已经登记的信息；事后更正不会偷偷改善历史预测。相同时点的未解决冲突显示 `conflict`，过期观察显示 `stale`，缺失显示 `missing`。

模型定义和完整模型分别有哈希。复盘可以加入后来观察，不能暗中改变目标、单位、行动和预测定义。应用保留模型版本链；更新必须带上当前版本ID。备份v3包含版本链与资源承诺，继续支持v1/v2恢复。

## 两条预测路径

### A. 显式情景

用户声明行动影响及延迟，系统按假设推演，在每个声明影响时点检查底线。`hold` 表示用户明确假设其他因素保持不变；默认的 `unknown` 不自动延续当前状态。

这些区间是情景假设范围，不是置信区间。`supported` 是输入的支持状态，内核不会把它当因果证明。前置行动按拓扑顺序返回，但没有连续时间调度器；延迟以决策时点为基准，不能当作真实执行日程。

### B. 从历史观察学习

当前实现 `AdaptiveKernel`：固定时域、带上下文及行动交互项的贝叶斯回归。它预测变化量，并替换同一测量上手写的影响；不会把两者相加制造更大收益。

特征：常数项、显式缩放的状态、行动是否执行、状态×行动、行动×行动。最多64个特征、6个当前行动、8个上下文和8个结果测量。该限制是当前工程范围，不是理论最优配置。

每个结果维度独立采用正态—逆伽马共轭模型：

```
y = xᵀw + ε
w | σ² ~ N(0, σ² λ⁻¹ I)
σ² ~ InvGamma(α, β)
```

每条真实结果更新后验；预测为 Student-t 分布，分别输出噪声方差与参数不确定性。先验默认 precision=1、alpha=2、beta=1；可显式配置，不能事后调参再把同一段回放当独立验证。数量缩放由用户定义，避免把单位差异误作重要性。

结果必须引用原始观察ID，并用哈希绑定执行时的完整行动定义。改变投入、含义或验收标准后应使用新的行动版本，不能复用旧结果冒充新行动效果。事前信息必须在行动开始前已知，结果时点必须匹配训练窗口。当前只接受精确点观察，不用区间中点假装真实标签。被更正而未重新关联的旧记录不参与当前训练。

以下情况拒绝据此自动推荐：历史总量不足、当前行动组合缺少支持、上下文越出观察范围、事前/结果基线未知。门槛是可配置的工程条件，不等于统计充分性。逐特征范围检查是粗糙的外推拦截，不能识别所有联合分布偏移或混杂。

预测范围是**在回归、先验和误差假设下的边际后验预测区间**。没有分布无关覆盖保证、跨维度联合保证、因果保证。若底线涉及学习结果，当前无法确认时域内部安全，返回 `intermediate_guardrail_unmodeled` 并阻止自动选择。

## 推荐如何取舍

1. 枚举明确的行动组合及“不新增行动”基线，当前每轮最多3个行动。
2. 检查前置行动、资源账户、完整耗时和底线；不缩短行动以凑预算。
3. 对每个目标条件保留一个缺口，沿目标树汇集子目标，不跨单位求和。
4. 用保守区间支配筛出 Pareto 候选。范围重叠时保留不可区分状态。
5. 仅依据用户声明的完整目标顺序作词典序选择；高优先目标未分出优劣时，不用低优先目标掩盖分歧。
6. 有唯一有条件优先项才进入自动推荐。否则显示需要补充观察或取舍。

这里的区间比较只针对给出的边界。学习模式用的是边际预测范围，不意味着整个多目标方案同时具有指定覆盖概率。目标期限目前作为元数据保存，不会暗中产生未公开的时限权重。

Laya / Ollama 的旧路径继续服务尚未配置人生模型的基础模式。配置了新模型以后，语言模型不能改写预算、完整时长、预测或最终排序。新链路不需要每次启动大语言模型。

## 学习、评测与结果闭环

采纳只记录承诺，完成只记录执行状态；二者都不被当作效果标签。效果来自后续按相同口径记录的观察。更新模型版本加入新观察和学习记录后，下一次评估会重建后验。当前没有自动从待办猜测训练记录，也没有后台自我修改代码或提示词。

`AdaptiveKernel.replay()` 按行动开始时间预测，只使用此前已登记的结果。每个结果单位单独报告 MAE、保持不变基线MAE、负对数预测密度、观察覆盖比例与平均区间宽度。不能只报命中率或测试数量。

合成复现实验：

```
python examples/generate_adaptive_fixture.py
python scripts/evaluate_life_kernel.py
python -m pytest -q
```

证据：`docs/evidence/adaptive-synthetic.json`，含三个固定种子、逐条预测、样本数、源文件哈希与运行环境。数据生成器故意使用适合当前回归形式的机制，优势属于合成工程验证，不能推广为真实个人收益。预测区间较宽、合成覆盖率高于声明质量，说明当前先验下预测偏保守；不能称作“已校准”。

## 未解决的核心问题

- 不规则观察、缺失并非随机、测量误差、非平稳、环境变化和多个未观察混杂。
- 当前不是完整的 POMDP：没有对隐藏人生状态建立经过验证的信念更新。
- 学习预测只覆盖固定窗口，不递归滚动生成长期人生轨迹。
- 没有自动发现价值、训练个性化奖励或从推荐点击推导幸福感。
- 没有反事实识别、策略离线价值估计或现实随机探索。
- 没有大规模求解器、多日连续日程优化或已验证的自动执行系统。
- 当前模型编辑通过文件导入，仍需要更易用的观测和目标关系编辑器。

验收必须先证明预测在冻结的真实历史窗口优于简单基线，再进行受控推荐试用。工程测试通过是运行条件，不能替代这项证据。

## 0.4补充：校准候选保持影子模式

`learning.calibration`可配置 `method=prequential_aci`、`step_size`、`window`、`min_samples`，用于历史对照。`forecast()`的权威上下界仍是原Student-t范围，候选写在 `candidate_interval`；`calibration.deployment=shadow_only`。这项隔离是因稳定场景改善而突变场景失败的实测结果，不是已经通过部署验证的校准策略。见 [本轮完整对照](CALIBRATION_EVALUATION.zh-CN.md)。

## 0.4.1补充：证据冲突不进入训练或回放

当同一测量在同一观测时点有未解决的不同报告，或者 episode 的事前引用不是行动开始时当前可用的观察时，该 episode 不参与训练、校准或最终回放。系统保留 `available_n/trainable_n/excluded_n` 和逐条排除原因，不用平均值、模型猜测或后来的结果修复冲突；未来才登记的冲突也不会改变过去 cutoff 的预测。完整规则、冻结反例和复现方式见 [证据资格门](EVIDENCE_GATE.zh-CN.md)。
