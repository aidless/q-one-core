# 双时间尺度预测：长期结构＋短期偏移

本轮建立了独立的双尺度研究原型，能够按日历间隔推演短期状态，并在结果晚到时按发生时间重建已知历史。**48个候选验收单元中33个通过，但稳定、噪声突变和部分行动效果变化单元未通过，因此不替换当前自动推荐内核。**所有性能证据均来自合成数据。

## 本轮推进

上一轮统一遗忘会同时削弱稳定行动知识，并在稀疏记录下触发近期信息不足。本轮将两类假设明确分开：共享的行动/上下文线性系数保留历史，短期加性偏移作为会随时间演化的不确定量。保留两部分之间的协方差；预测范围包括观测噪声与参数/状态的不确定性。

参考[官方Dynamax线性高斯实现](https://github.com/probml/dynamax/blob/ffc626bf89bf07c7ae7064922f6a373d013c4b17/dynamax/linear_gaussian_ssm/inference.py)、[BONE论文](https://arxiv.org/abs/2411.10153v3)后自主推导实现，未运行第三方实现、复制代码或引入JAX。BONE仓库未提供许可证，故只作论文入口；Dynamax MIT许可证与最新release1.0.3已核查。[来源和假设边界](../literature/notes/two-scale-2026-10-25.md)、[固定版本记录](../literature/two-scale-source-probes.json)。

这个原型不是完整的人生状态模型。结构项不等同人的能力，短期项不等同情绪；二者尚未被个人数据识别。固定一天结果窗口没有扩展为长期目标或因果收益。当前原始支持门和上下文范围检查也不证明历史关系尚未失效。

## 模型与时间语义

`结果变化 = 行动/上下文结构项 + 短期OU偏移 + 观测噪声`

短期项半衰期固定16天，平稳方差固定为一个公共噪声尺度，都是事前假设。全部协方差共享同一个未知方差并使用inverse-gamma先验；边际预测为Student-t。这不是分别学会了过程噪声和测量噪声的模型。

每次预测先选择`recorded_at <= as_of`且未被更正淘汰的结果，再按`ended_at`重建滤波，最后预测到`as_of + horizon_days`。晚到旧结果不能被当作今天的冲击；未来标签不能参与此前预测。缺少观察时只推演状态和不确定性，不编造测量值，也不使用未来数据平滑过去。

独立数学对照使用“线性核＋OU时间核＋观测噪声”的完整联合高斯条件分布；验证不规则时点下的均值、预测尺度和方差后验。短期方差为0时回到原回归；跨长时间空档只衰减短期状态，不丢掉静态系数的后验。数学一致性不能证明这些假设适合真人。

均值变化场景汇总MAE比值为0.34506；这只是两种合成目标的工程诊断，不能作为人生价值或真实收益分数。它也不能掩盖稳定场景退化、噪声变化时漏覆盖、特定行动关系变化时的点误差失败。旧基线此前也存在漂移覆盖不足，本轮保留它不表示旧内核已经可靠应对漂移。

这次推进明确了三项后续瓶颈：稳定与变化假设需要可检验的选择机制；公共方差不能单独适配噪声突变；一个共享短期偏移不能覆盖所有行动响应的变化。不能靠在已看过的八类场景上调参来宣布解决。
