# Q-One 研究来源库

这是跨三个仓库的唯一来源登记处。入口是[融合蓝图](../docs/SYNTHESIS_BLUEPRINT.zh-CN.md)与[研究矩阵](MATRIX.zh-CN.md)。`q-one-agent` 与 `q-one-life` 各自保留实现路线，并引用此处的稳定来源 ID。

## 本轮覆盖与限制

本轮初筛 29 条来源，包含论文、官方文档、开源实现、行为与系统方法，以及用户指定的两个社区工程。检索日期为 2026-10-23。这是一轮针对架构的定向筛选，尚未做系统综述、全部全文精读、全部模型横评或官方基准复现。

`source-registry.json` 是结构化真相源；`MATRIX.zh-CN.md` 是阅读索引；`notes/` 为每条来源记录阅读范围、可借鉴机制、适用条件和实现位置；`references.bib` 提供引用键。所有 `project_result=not_evaluated` 表示尚无本项目性能证据。单个页面已读不等于方法已经验证。

## 纳入与采用流程

1. **发现**：写明问题、检索式、检索日期与渠道。
2. **核查**：核对标题、作者或机构、URL、版本；arXiv 要打开 abs 页校验号题一致。
3. **理解**：区分原来源内容与本项目的设计判断；记录仅读摘要、README、选定段落或全文。
4. **映射**：每条候选必须有待解决问题、目标模块、比较基线和失败条件。
5. **实验**：固定任务集、输入、模型版本、评测口径；保存失败、弃权与成本。
6. **采用**：只有完成项目内验收的机制才能标记为已采用；允许结论为无增益或负增益。
7. **维护**：每个研究迭代检查来源更新；产品版本变化后重新核验适用性。这里没有建立自动监控。

来源可核查、方法可复现、局部实验通过、实际用户获益是不同状态，不合并成一个“可信分”。原论文报告不自动成为 Q-One 的实验结果。社区示例默认列为工程参考。

## 原创与许可

本轮仅保存元数据和自行撰写的摘要，不复制论文全文、模型权重或第三方实现。代码、模型权重、训练数据、评测集和托管 API 分别核查授权。Q-One 自身的 MIT 许可证不覆盖这些外部材料。`license=null` 表示未确认授权，不表示可任意复用。

## 新来源模板

新增条目应包含 `id`、`title`、`url`、`type`、`read_level`、`checked_date`、`source_summary`、`adopt`、`limitations`、`integration`、`priority`、`decision` 和 `project_result`，同时补笔记与 BibTeX。没有实验时结果保持 `not_evaluated`。不要为凑数量收集重复论文，也不要把当前模型列表称为最新最全榜单。
